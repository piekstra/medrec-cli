# medrec

A household's medical records in a plain Drive folder: people, intake of
scanned paper and files with local OCR, imaging studies, records from provider
and insurer CLIs, timelines, search and notes. A member of the `piekstra-cli/1`
family; it holds no provider credentials (provider CLIs fetch, medrec files).

This repository is being built; the records commands land by pull request.
